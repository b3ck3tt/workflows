# SNCS: Learning from Prior Experiments — Meta-learning Models of Workflow Performance

Code for the SN Computer Science article
(DOI [10.1007/s42979-026-05295-9](https://doi.org/10.1007/s42979-026-05295-9)),
the extended version of the WEA 2025 conference paper *Meta-learning for
Performance Prediction of Machine Learning Models*.

**This directory is the SNCS study.** The rest of this repository
(`openml_flow.py`, `experiments.ipynb`, `recommender_experiments/`) belongs to a
different line of work on the same data — a task-grouped, explanation-oriented
protocol — and does **not** reproduce the numbers in the SNCS article. The two
differ deliberately: see "Relation to the rest of the repo" below.

## Running it

Data comes from OpenML and is fetched by the notebook itself; no dataset files
are required to start. Dependencies: `openml`, `scikit-learn`, `pandas`,
`numpy`, `sentence-transformers` (D0 only), `shap`, `seaborn`, `matplotlib`,
`tqdm`.

Two caveats worth knowing before you run it:

- The notebook writes and re-reads intermediate dumps (`flows*.txt`, `ewf.txt`,
  `dsets.txt`, `taskdata.txt`) as a download cache. **These are not included** —
  they are hundreds of megabytes and are regenerated by the collection cells.
  Expect the first full run to spend a long time on OpenML API calls.
- Cell outputs are retained, so the reported tables and figures can be read
  without re-running anything.

## Relation to the rest of the repo

The SNCS study cross-validates over **shuffled splits of individual
workflow–dataset evaluations**, so evaluations of a dataset that also occurs in
training may land in the test fold; it reports test *R²* ≈ 0.80. The
explanation-oriented study in the repository root instead assigns **all rows of
a task to one fold** and aggregates repeated evaluations of a pair into a single
target, which is a stricter setting and yields substantially lower *R²*. The
difference is protocol, not a contradiction — interpolating within known
datasets versus generalizing to new ones.
